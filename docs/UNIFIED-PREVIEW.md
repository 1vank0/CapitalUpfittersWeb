# One reviewable website version

This branch consolidates the website deliverables on the latest redesigned site. It does not change production or start the measurement baseline.

## Present together
- Existing indexed routes, sitewide shared UI and service decision guidance.
- Light/black visual pilot on bedliner and bed covers only, with exact pilot copy/prices/forms retained.
- $595 + tax Patriot Liner starting price, $795 long bed and condition/accessory caveats; UV+ copy.
- Nine cover choices, $1,050 Westin and $1,350 MX4 installed, $50 bundle saving; eligible-only RealTruck double warranty and separate six-month installation coverage.
- Genuine shop proof and attributed service reviews, undercoating starting anchors and honest availability CTA.
- Fleet/dealer/project routing, partner handoff and customer-supplied hitch synchronization.
- Gallery and factual project detail routes using existing published shop imagery. No fabricated before/after comparisons.
- Back-to-top and hours status, with unknown fallback until verified published CMS hours are connected.
- Gated measurement with empty-by-default runtime IDs, sanitized source capture and tested lead IDs. Pilot pages explicitly tagged light-pilot; other pages baseline.
- Payload CMS source in `cms/`, excluded from this static deployment. This is a separate field-based admin application, not a live visual page editor or connected production CMS.

## Deliberately not activated
- Production rollout, tracking, measurement baseline, phone tracking or third-party account configuration.
- Real GA4 DebugView, real email/storage delivery, Shopmonkey estimate/booking reconciliation.
- Hosted Payload database/storage, initial admin/recovery, publication and hours synchronization.
- Spanish pages until service capability and rollout approved; homepage shop video pending actual footage.
- Broader light-theme rollout before pilot evaluation; immediate hitch checkout until catalog/fitment/pricing/payment requirements are supplied.
