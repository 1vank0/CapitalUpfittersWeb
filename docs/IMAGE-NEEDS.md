# Image needs

The redesigned UI uses explicit placeholders where an authentic Capital Upfitters job photo is not verified. Replace each slot through its `data-image-need` ID. Never present generated pictures as our shop, team, customers or completed jobs. Existing real gallery feed integration is preserved.

## Capture and delivery

- Photograph actual work in bright, neutral shop light. Match crop, angle and color across each set. Get customer permission and avoid readable plates, VINs and personal details.
- Deliver WebP or AVIF plus the original. Hero ≤200 KB, card ≤100 KB; include intrinsic width/height and useful alt text. Keep controls and copy in HTML.
- Generation prompts below are for **clearly labeled illustrative concepts only**. Use real shop photography for evidence of completed work. No generated testimonial imagery.
