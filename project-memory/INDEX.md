# Project Memory Index

Read `CURRENT-STATE.md`, `REQUIREMENTS.md`, and `DECISIONS.md` at the start of every session (mandatory). Read the rest as relevant to the active phase.

| File | Contents | Read when |
|---|---|---|
| `CURRENT-STATE.md` | Active branch, phase, done/unfinished, blockers, Preview URL, next action | Always, first |
| `REQUIREMENTS.md` | Non-negotiable constraints and requested behavior | Always |
| `DECISIONS.md` | Material decisions with reasoning, alternatives, date, source | Always |
| `PROJECT-CONTEXT.md` | Business, brand, audience, service, architecture context (tagged by verification status) | Before writing any customer-facing copy or claims |
| `VERIFIED-FACTS.md` | Facts confirmed by site/repo/business records/Ivan | Before publishing any factual claim |
| `FACTS-TO-VERIFY.md` | Claims that may be true but are NOT cleared to publish | Before writing trust/certification content |
| `CONTENT-INVENTORY.md` | Current pages, sections, duplicates, gaps, preservation decisions | Audit and sitemap phases |
| `ASSET-INVENTORY.md` | Images, video, logos, galleries, usage rights, replacement status | Media and design phases |
| `CONNECTORS.md` | Connector status (no secrets) | Any phase needing external tools |
| `OPEN-QUESTIONS.md` | Unresolved material questions | Always, check before assuming |
| `TASK-LOG.md` | Dated log of completed work, files, commits | End of every phase |
| `HANDOFF.md` | Compact restart point for a new session/agent | Always, first — and update last |

Root-level deliverables outside `project-memory/`: `reports/existing-site-audit.md`, `research/*`, `best-principles.md`, `reports/design-comparison-matrix.md`, `experiments/direction-{a,b,c}-*`, `qa/final-qa-report.md`.
