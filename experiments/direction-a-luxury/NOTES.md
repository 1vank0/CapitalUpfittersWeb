# Direction A — Luxury Automotive — Notes

This prototype keeps the live site's actual design DNA (Manrope/Inter, `#1d1d1f` ink, `#0071e3` Signal Blue, zero shadows, pill buttons — verified against `base.css`, not the stale README/header-comment claims) but pushes it toward restraint: a deeper near-black (`#050505`) replaces pure black for hero/footer sections, the accent color is used in exactly two places (primary CTA fill, focus rings) so it reads as a rare signal rather than decoration, spacing is stretched to an editorial scale (`--section-pad` up to 9rem), and every image is full-bleed with a dark gradient rather than boxed/cropped into a card grid. The homepage hero keeps the required `assets/amp-powerstep.mp4` unchanged, embedded muted/looped behind the headline with a poster fallback from `media/gallery/homepage/hero-*.webp`. Imagery throughout comes only from the existing `media/gallery/homepage/` (audience/service/craft photography) and `media/next/` (service icons in the tile grid) — nothing generated. Content follows `best-principles.md` §8's hierarchy exactly (audience-aware hero → category overview → differentiation → audience paths → trust strip → service grid → FAQ → phone-first final CTA), and every trust element is either verified business info (address/phone/hours from `PROJECT-CONTEXT.md`) or an explicit `[…verify before launch]` placeholder — no review counts, years-in-business, or "authorized dealer" language, since those are all on `FACTS-TO-VERIFY.md`. `bedliner.html` extends the same system into a service-page template (spec strip, numbered process, written pricing table, fitment note, related services) to show the direction holds up past the homepage. JS is limited to one file (`direction-a.js`): nav scroll-state toggle and mobile-menu open/close, nothing else — the FAQ accordion uses native `<details>`/`<summary>` instead of JS.
