# Direction C — Conversion-First: Notes

This prototype front-loads the lead-generation path instead of the brand story: the hero sits directly above a three-step "Find My Fit" picker (audience → services → contact) that mirrors the real site's proven `quote-form.js`/`lead-form.js` split — UI-only state management here, single simulated submit, no `fetch()` calls anywhere in `direction-c.js` (see its file header). CTA color (`--cta: #ff5a1f`) is the one deliberate divergence from `base.css`'s Signal Blue tokens, reserved only for primary conversion actions so it reads unambiguously as "the thing to click" against everything else; all other tokens (spacing, radius, type scale, surface/ink colors) are lifted straight from the real `base.css` so this direction still feels native to the brand. Every category tile, gallery photo, and the service page's "Add to Quote" card deep-links back into the picker with `?audience=&service=` pre-selection (`window.CUFindMyFit.preselect`), so proof and service discovery are never more than one click from the quote flow — per the audit's Alliance Fleet anti-pattern (strong credibility, buried conversion path) and the Leonard USA reference pattern (no-deposit + same-business-day response promise, reused verbatim from the real `lead-form.js` success-banner copy since it's an actual operational commitment already coded into the site, not a new claim). Trust numbers that live on `FACTS-TO-VERIFY.md` (Google rating, certification status, "years in business") are shown as `[verify before launch]` placeholders rather than the hard numbers the real service pages currently publish unverified. All imagery comes from `media/gallery/homepage/` (AVIF+WebP with `<picture>` fallback); the homepage hero embeds the real `assets/amp-powerstep.mp4` locally (no external network dependency, unlike the live site's external playlist) so the protected video asset is represented without altering it. A sticky bottom CTA bar (Call / Get My Quote) is mobile-only (`<860px`) per task spec §13, and the service page adds a second sticky bar that appears once the in-context "Add to Quote" card scrolls out of view.
