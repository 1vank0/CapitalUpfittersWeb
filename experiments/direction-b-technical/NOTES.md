# Direction B — Technical Authority — Notes

This prototype pushes the real `base.css` Apple-inspired tokens (ink `#1d1d1f`, Signal Blue `#0071e3`, Manrope/Inter) toward a denser, engineering-department register rather than a marketing one: an added `IBM Plex Mono` type for every spec figure, KPI, and process number; hairline dividers and a blueprint-grid motif instead of soft drop-shadow cards; and content structured around *proof of process* (a 4-step install rail, a hitch-class spec table, a non-configurator "does this fit my vehicle" widget, and a warranty/documentation panel) rather than lifestyle imagery. The one deliberate content risk I took: a dedicated, amber-flagged "Verification Status" panel that lists every item from `FACTS-TO-VERIFY.md` (Patriot Liner authorization, years in operation, family ownership, review counts, etc.) as explicitly *pending* rather than omitting them — this demonstrates the trust-gating pattern the redesign requires (`best-principles.md` §17) instead of just avoiding the topic, and doubles as the fleet-credibility zone's partner-badge pattern (Patriot Fleet Solutions / RealTruck / eTrailer / Stealth Hitches, all flagged pending). All copy, KPIs, and spec-table figures are either repo-verified facts (address, hours, 16 service count, SAE hitch classes) or process description — nothing from the verify list is stated as fact. Images are drawn from `media/gallery/homepage/` (AVIF+WebP `<picture>` sources) with `media/next/` as a fallback for categories the gallery set doesn't cover; the homepage video is embedded unchanged at `assets/amp-powerstep.mp4` as a muted hero background. JS (`direction-b.js`) is ~100 lines: mobile nav toggle, FAQ accordion, a non-functional fitment-form handler that always routes to "call to confirm," and a progressive-enhancement scroll-reveal — no framework, no build step, no network calls.
